## Implementation system

- Use English throughout public project pages, including figure labels and legends. Name projects for the engineering work and objectives; omit client names from titles, descriptions, captions, and public project URLs. The steam-bath case study is “Steam Bath Ventilation Improvement,” focused on eliminating hot spots, improving air distribution, and lowering average room temperature. Distinguish project objectives from demonstrated numerical results.

- Project naming: use professional, descriptive names consistently in page headings, browser titles, social metadata, homepage entries, and navigation. The master's testbed project is named “Planar CubeSat.” Use direct technical section headings; avoid slogans as project names.
- Project-page depth: the owner wants dedicated pages to show the engineering work in detail, without a short-summary limit. The lava-rock page includes component views, experiments, load calculations, FEA setups/results, and thermal analysis directly on the page, with section navigation and an accessible figure viewer. Original image links work without JavaScript. The steam-bath page follows the same format with nine chapters, 24 figures, numerical comparison tables, and downloadable result data. CAD views come from final STEP models; charts distinguish site observations, simulated comparisons, and the engineering recommendation.
- Background: off-white `#f6f6f4`; ink `#191d1b`; accent `#245b46`; muted copy `#5d635f`; rules `#c1c5bf`.
- Typography: self-hosted Instrument Serif for titles and Geist for body text and controls, preserving the original font licenses.
- Layout: 1280px maximum content width; open sections divided by rules; a split introduction and featured project; image cards for every project; three-column desktop and two-column tablet gallery; two-column about section; green contact band. Collapse to one column on phones.
- Media: real CAD renders and screenshots, no tint overlays. Crop only through CSS media frames; full source images appear in case studies.
- Components: rectangular buttons, underlined text links, typography-only identity, plain category buttons with selected underline, static story pages. No remote frontend dependencies.
- Motion: subtle hover scale and smooth anchor scrolling, disabled with reduced-motion preference.
- Behavior: the featured thesis stays above the filtered seven-project index. Category buttons update visible articles and announce result counts. Without JavaScript every project remains visible.
- Content: only public projects. Hardware, simulation, and development status are explicitly distinguished. The existing résumé remains available.
