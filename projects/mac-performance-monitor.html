Mac Performance Monitor

Pulse is a native Mac app I wrote in SwiftUI for Apple silicon. It shows CPU, GPU, memory, disk, network, and the processes behind them. This is a 2.0 preview. If a sensor is not available, the app leaves it blank.

The application

The window shows CPU, GPU, memory, disk, and network next to the process list. A menu-bar panel stays up when the main window is closed.

Workloads

Helpers get grouped with the app that owns them, and a few development tools are recognized as their own workload. The app keeps session history and can raise an alert if a reading stays high. Click a point on a chart and you see the processes from that sample.

What it will not invent

Numbers come from macOS. If the machine or the OS will not provide a sensor, that tile stays empty. This build is a preview for Apple silicon. Which sensors exist depends on the Mac.
