Making Mac resource usage visible.

A native SwiftUI performance monitor for Apple silicon, designed to explain system activity through local metrics, process views, and charts.

Scope
Native app & system telemetry
Status
2.0 preview
Tools
Swift · SwiftUI · Native macOS counters
View on GitHub ↗

The application

Pulse presents CPU, GPU, memory, disk, and network activity alongside process information. A menu-bar panel keeps a compact view available while the full dashboard is closed.

Understanding workloads

The app groups application helpers and recognized development workloads, retains session history, and supports optional sustained alerts. Charts can be inspected at a specific point in time to connect a system reading with the processes visible in that sample.

Measurement boundaries

Metrics come from native macOS interfaces. Hardware or operating-system restrictions are represented as unavailable readings rather than invented values. The current release is a preview for Apple silicon; sensor availability varies by system.
