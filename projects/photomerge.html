Photomerge

Photomerge turns sequential overlapping photographs into a high-resolution panorama through a local desktop workflow.

Scope
Image processing & desktop interfaces
Status
Desktop MVP
Tools
Python · OpenCV · SwiftUI · Qt

The workflow

Import photos, create a panorama, review the result, and export. The application keeps the photo set, preview, and settings together, with progress and cancellation support for processing operations.

Image review and editing

The project combines a local stitching engine with control-point tools, overlays, and full-resolution export. The Mac interface uses SwiftUI; a Python and Qt interface supports the Windows workflow.

  • Analyze overlap and align successive photographs.
  • Inspect the panorama and adjust control points.
  • Review processing activity and export the resulting image.

Mission planning tools

A companion flight-planning workflow edits a local copy of an existing DJI waypoint mission, with grid planning and backed-up saves. It prepares mission files; it does not directly connect to or control an aircraft.
