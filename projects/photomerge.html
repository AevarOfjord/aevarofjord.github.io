Photomerge

Photomerge stitches a run of overlapping photos on the desktop, then lets me check the control points before export. The Mac app is SwiftUI. The Windows side is Python and Qt. A separate screen edits a local copy of a DJI waypoint file. It does not connect to an aircraft.

Scope
Image processing & desktop interfaces
Status
Desktop MVP
Tools
Python · OpenCV · SwiftUI · Qt

The workflow

Import the photos, stitch them, look at the result, export. The photo set, the preview, and the settings stay in one window. Long stitches can be cancelled.

Checking the stitch

Alignment runs locally. I can open the control points, see the overlap, and export at full resolution. SwiftUI on the Mac. Python and Qt on Windows.

  • Find the overlap and align the frames.
  • Move control points if the stitch is wrong.
  • Export the panorama.

Waypoint files

A second screen edits a local copy of a DJI waypoint mission, including a simple grid, and saves a backup first. It writes a mission file. It does not talk to the aircraft.
