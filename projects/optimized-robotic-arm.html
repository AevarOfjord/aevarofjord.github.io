08 / Robotics · Optimization

Finding a pose the motors can hold.

An interactive arm-modeling tool for finding joint poses that lift a payload to a target while respecting motor torque limits.

Scope
Kinematics & torque-aware pose optimization
Status
Working software MVP
Tools
Python · React · Three.js

The problem

Reaching a position is only part of a lifting task. The selected pose must also keep the modeled joint loads within the available motor torque.

The model and interface

The MVP models base yaw, shoulder pitch, elbow pitch, and wrist pitch. A pure-Python backend provides forward kinematics and static torque estimates, while a React and Three.js frontend presents the arm and target in 3D.

  • Explicit joint axes and a consistent vertical zero-pose convention.
  • Payload and gravity torque estimates for candidate poses.
  • An optimization API that searches for feasible target-reaching configurations.

What is modeled

This version uses a simplified static lift model. Dynamic trajectory optimization and MPC are future extensions, rather than results claimed for the current implementation.
