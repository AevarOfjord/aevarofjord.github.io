# Aevar Oefjoerd

Personal site published with GitHub Pages from `main`. Static HTML and CSS — no build step.

Preview locally:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

- `index.html` — resume
- `portfolio/` — planar CubeSat air-bearing testbed case study
- `files/Aevar_Ofjord_Portfolio.pdf` — portfolio PDF
- `styles.css` — layout and print styles
- `fonts/` — self-hosted SIL Open Font License webfonts (Geist and Instrument Serif)
- `Aevar-Oefjoerd-Resume.pdf` — resume
